# Milestone context

When a milestone is explicitly requested, keep its implementation context in one
file here, such as `m6-normalization.md`: objective, scope and exclusions, relevant architecture
links, acceptance criteria, and observed validation evidence.

Read that file and directly relevant architecture documents for implementation.
Keep repository-wide rules in `../../AGENTS.md` and milestone status in
`../roadmap.md`. Existing `../m0-validation.md` through `../m5-validation.md`
remain in place as historical evidence; do not move, rewrite, or consolidate them.

No M6 implementation is started by creating this directory.
